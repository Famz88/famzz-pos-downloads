BEFORE YOU GET STARTED

A few useful answers.

How do I install FamZz POS?

Download the latest Windows x64 installer and checksum from the release page. Verify the checksum, run the installer, then set up your local owner account. The installer is unsigned, so Windows may display an unknown-publisher warning. Test your printer and workflows before using it for live service.

View downloads and release notes ↗
Does it work without the internet?

The Windows desktop edition supports local ordering and records on your PC. Online services and external integrations require connectivity. The browser demo is not a replacement for the installed offline edition.

How is my annual license activated?

Email your company name, Installation ID and required user/outlet limits. After arrangements are confirmed, we supply a company-specific license file to import under PC settings → License. License issuance is handled by FamZz; customers cannot issue their own licenses.

Does it process card payments?

FamZz POS records the payment method. It does not automatically charge a card terminal or open a physical cash drawer. Confirm hardware and integration needs with us before purchase.

How does automatic day close work?

Completed days close after midnight while an online manager session is open, or catch up when the app is reopened. Running orders and open cash shifts must be reconciled first. Manual closing remains available; unattended server-side midnight closing is not yet available.

Can my company register for the online POS?

Public online registration is not open yet. You can try the sample-data demo now, or email us about the available Windows desktop edition.
